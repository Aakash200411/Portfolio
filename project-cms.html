Content Management System

A role-based CMS built for academic use, managing users, subjects, marks, attendance, and learning resources through one admin dashboard. This is the system behind my VESIT internship work.

Repository

Overview

Built to replace a set of manual, spreadsheet-based processes at VESIT with a single system administrators could manage directly — user accounts, attendance, marks, and announcements, all in one dashboard with role-based access.

Features

  • Role-based access control for Admin and Regular User accounts
  • Subject and marks management across tests and courses
  • Attendance recording and per-user attendance history
  • Announcements and resource/video uploads for students

Stack

Core PHP backend, MySQL database, and a vanilla HTML/CSS/JavaScript frontend, run on XAMPP.
