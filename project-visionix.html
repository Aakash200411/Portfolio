VisioNiX

A multimodal AI assistant that combines vision models, OCR and a vision-language model to understand images and hold conversations about them, plus a UI for fine-tuning and deploying custom models. Built with a 4-person team.

Repository Publication (VDI-Z)
Built collaboratively with Aryan Kate, Bhuvan Patil, and Siddhesh Patil.

Overview

VisioNiX runs every uploaded image through a stack of specialised models, then lets the user ask questions about it in a chat. The structured outputs ground the conversation so answers refer to what is actually in the image.

Analysis pipeline

  • Captioning: BLIP generates a natural-language description.
  • Object detection: YOLOv8 finds and labels objects.
  • OCR: docTR extracts printed and handwritten text.
  • Scene classification: a Places365 ResNet-18 labels the setting.
  • Image embeddings: normalised CLIP vectors feed a FAISS index for similarity search over previously analysed images.
  • Conversation: a Qwen vision-language model served through Ollama answers questions using the image and the extracted context.

Fine-tuning and deployment

Users can upload their own dataset, choose a task (classification, detection or segmentation), set training parameters, and train a YOLOv8 model from the UI. Training runs as a background job with logged metrics, and the finished model can be published to the Hugging Face Hub and deployed as a Gradio Space with a generated model card.

Platform

Python/Flask backend with JWT-based auth and Supabase for users, chat sessions and training-job records; React and Tailwind frontend.
