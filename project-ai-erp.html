AI Assistant ERP

A full-stack ERP system with an AI chatbot layered on top, so users can query business and institutional data conversationally instead of digging through menus.

Repository

Overview

The system pairs a standard ERP backend (user, resource, and records management) with a chatbot that answers questions and handles FAQ-style requests directly, using an LLM API layered behind an Express backend.

Architecture

  • Frontend: React interface for both the chatbot and the underlying ERP dashboard.
  • Backend: Node.js and Express, handling routing, data models, and business logic.
  • AI layer: A separate service handling LLM API calls that the backend queries for chatbot responses.
  • Database: MongoDB for storing users, records, and FAQ data.

What it does

Instead of navigating through separate ERP screens to find attendance, resource, or user information, a user can ask the chatbot directly and get a routed, data-backed answer.
